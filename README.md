## 🔍 Project Details

### 1. Customer Product Sales Analysis

Multi-page report analyzing purchasing behavior, product performance, and sales trends.

**Files:** `Customer Product Sales Analysis Dashboard.pbix` · `.pdf` · `.png` · `.mp4` · `Testing Data.xlsx`

- KPI cards for revenue, orders, and customer count
- Time-series trend analysis with drill-down capability
- Customer segmentation and product category breakdowns

---

### 2. Coca-Cola Sales Dashboard

Regional sales performance report with multi-dimensional analysis.

**Files:** `Coca Cola Sales Dashboard.pbix` · `.pdf` · `.mp4`

- Regional performance heatmaps
- Product-line revenue comparisons
- Interactive filtering by region, product, and time period

---

### 3. E-Commerce Sales Dashboards

Two dashboards providing insights from order-level details to high-level KPIs.

**Files:** `E-Commerce Sales Dashboard.pbix` · `v2.pbix` · `v2.pbit` · `.pdf` exports · `Orders.csv` · `Details.csv`

- Order funnel visualization and conversion metrics
- Category-wise and sub-category revenue breakdown
- Includes a `.pbit` template for reusable deployment

---

### 4. Reddit Stock Price Analysis

Historical stock price analysis for Reddit (RDDT) uncovering price patterns and trading signals.

**Files:** `Reddit Stock Price Analysis Dashboard.pbix` · `RDDT.csv`

- Price trend visualization with moving averages
- Volume analysis and trading pattern detection
- Historical performance tracking

### 5. Sales Data Dashboard

General-purpose analytics dashboard integrating multiple data sources.

**Files:** `Sales Data Dashboard.pbix` · `salesdata.pbix` · `.pdf` · `Category data.xlsx` · `Sales data.xlsx`

- Multi-source data integration
- Dynamic category filtering and cross-highlighting
- Period-over-period comparison metrics

### 7. Supermarket Sales Dashboard

Sales performance analysis across supermarket branches.

### 8. Food Nutrients Analysis

### 9. Future Tweet Sentiment Analysis

Sentiment analysis on Twitter/X data, visualizing public opinion trends.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** — Dashboard development & data modeling
- **DAX** — Custom measures, calculated columns & KPIs
- **Power Query (M)** — Data extraction, transformation & loading
- **Excel / CSV** — Source data

---

## 🚀 Getting Started

```bash
git clone https://github.com/dev-mangukiya/PowerBi-Dashboards.git
```

Open any `.pbix` file in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free). Each folder also includes PDF exports and video walkthroughs if you prefer to browse without Power BI.
